# WebSite Rent Flat — Version 1.0

Modernized version of the apartment rental website.

## Stack

- Next.js
- React
- TypeScript
- CSS
- Existing apartment images from the repository

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Routes

- `/` — homepage and search
- `/apartments` — apartment catalog
- `/apartments/[slug]` — apartment details

## Version 1.0

The modernization is being developed on the `modernization` branch. The original static site remains on `main`.

Next steps: PostgreSQL + Prisma, authentication, real availability calendar, bookings, favorites, reviews, landlord dashboard and admin panel.
